ABC Supermarket Information Systems Modernization Project
📋 Project Overview

This project analyzes **ABC Supermarket's** current information systems and proposes modernization solutions to enhance operational efficiency, customer experience, and competitive positioning in the retail industry.
 🎓 Academic Information

| Detail | Information |
|--------|-------------|
| **Program** | Higher Diploma in Computing and Software Engineering |
| **Module** | Business Information System (CSE4003) |
| **Group** | Golden Starrs |
| **Institution** | Cardiff Metropolitan University / ICBT |

 🎯 Project Objectives

1. Analyze existing information systems at ABC Supermarket
2. Identify functional areas and their information needs
3. Evaluate current systems and industry trends
4. Propose modern technology solutions
5. Provide data-driven recommendations for business improvement

 📊 Key Deliverables

1. Functional Areas & Information Needs Analysis
- **Marketing** – CRM for customer research and sales trends
- **Finance** – TPS, MIS, ESS for budgets and financial reporting
- **HR** – Payroll processing and performance tracking
- **Supply Chain** – ERP for inventory and supplier management
- **Customer Service** – CRM for feedback and complaint tracking

2. Current Systems Assessment
| System | Purpose |
|--------|---------|
| TPS | Daily transaction recording |
| MIS | Management reporting |
| DSS | "What-if" analysis & forecasting |
| ERP | Cross-department integration |
| CRM | Customer preference tracking |

3. Competitive Analysis & Trends
- ERP implementation for operational integration
- CRM for personalized customer engagement
- AI for demand prediction
- Cloud computing for scalability
- IoT smart shelves for inventory tracking

4. Proposed Modern Systems
| System | Key Benefit |
|--------|-------------|
| **AI-Powered CRM** | Predictive analytics & personalized promotions |
| **Cloud-based ERP** | Centralized real-time data management |
| **BI Dashboards** | Real-time KPIs & faster decisions |
| **IoT Smart Inventory** | Automated stock monitoring |
| **Mobile Commerce** | Click-and-collect & digital payments |
