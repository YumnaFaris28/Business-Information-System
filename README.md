# Computer Architecture – Meditech IT Infrastructure Design | CSE4001

📋 Project Overview

This individual coursework explores **Computer Architecture** fundamentals and applies them to design a complete, secure, and efficient **IT infrastructure for Meditech** — a healthcare organization based in Jaffna. The project bridges theoretical concepts (binary math, Boolean logic, logic circuits) with practical implementation (hardware specs, software solutions, security policies) for a real-world medical environment.

🔒 System Design & Security
- Role-based access control and permissions
- VPN + two-step verification for remote work
- Encrypted backups and 24/7 monitoring
- Conflict resolution (e.g., bandwidth allocation, nighttime backups, dedicated voice networks)

 ⚙️ IT Infrastructure Evaluation
- **Strengths:** Dedicated specialists, cloud flexibility, efficient team division
- **Weaknesses:** Single point of failure, insufficient encryption, lack of automation
- **Recommendations:** Zero-trust security, AI threat detection, hybrid cloud, blockchain for records, IoT tracking, AI chatbots
- **OS Strategy:** Mixed Windows/Linux environment based on role requirements
- **Maintenance:** Automated Windows updates, monthly Linux patches, BitLocker/LUKS encryption, Active Directory, Veeam backups with cloud redundancy



💡 Key Recommendations

1. **Adopt a hybrid OS approach** — Windows for compatibility, Linux for development and security
2. **Implement zero-trust security** with encryption, access controls, and AI monitoring
3. **Automate backups and updates** to ensure data safety and system reliability
4. **Use cloud + local infrastructure** for flexibility and disaster recovery
5. **Integrate modern tools** (blockchain, IoT, AI chatbots) for future-proofing
